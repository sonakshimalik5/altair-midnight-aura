# Midnight Bloom Launch

Build a premium, cinematic landing page for a new fragrance called ALTAIR, designed as part of the Sarkar fragrance brand universe.

Reference https://sarkar.store to understand Sarkar's existing visual identity, perfume presentation, pricing style, typography, tone and overall premium-but-accessible positioning.

Product

Name: ALTAIR
Notes: Night Jasmine, Datura, Cherry, Mulberry, Wood
Fragrance profile: Floral · Fruity · Woody · Night
Tagline: “For nights that smell like rain and feel like confidence.”

Price: ₹1,199
Size: 100 ML PARFUM

Critical packaging rule

Do NOT redesign the Sarkar perfume packaging.

If a Sarkar product image is used, preserve the bottle, label, cap, colors and proportions exactly as provided. Do not create a different bottle.

The creativity should come from the website design, photography, layout, typography, copy and atmosphere.

Visual direction

Create a dark, sophisticated, nocturnal aesthetic inspired by:

midnight rain + dark berries + night-blooming flowers + polished wood + quiet confidence

Use:

deep midnight blue

black/charcoal

ivory typography

very subtle metallic accents

cinematic lighting

reflections and shadows

generous whitespace

elegant editorial typography

Do not make it overly pink, feminine, bright, floral or cliché-luxury.

Design requirements

Make the website feel like a real premium fragrance launch, not a generic website template.

Use subtle animations and smooth scrolling, but prioritize visual quality and performance.

Make it fully responsive for desktop and mobile.

The overall design should feel like:

Sarkar's existing fragrance world + a darker, mysterious midnight identity for ALTAIR.

Core principle:

Do not redesign the product. Design the world around it.
